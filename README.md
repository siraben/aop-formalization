# Algebra of Programming in Agda

Agda formalization of definitions, calculations, and programs from Richard Bird and Oege de Moor’s *Algebra of Programming*.

Run `nix flake check` to type-check [`Everything.agda`](src/Everything.agda), which imports all modules. For interactive work, run `nix develop` and open a `.agda` file in your editor. The proofs use Agda builtins with `--safe --without-K`.

In the [company-party example](src/AoP/Chapter07/PartyExample.agda), a supervisor and a direct report cannot both attend. Ada scores 8; her reports Bo and Cy score 5 each. The best guest list is `[Bo, Cy]`, or `[Ada]` if the president must attend. The [proof](src/AoP/Chapter07/Party.agda) calculates the best plan for each subtree under both choices for its supervisor.

## Source layout

[`src/AoP`](src/AoP) has one directory per chapter (`Chapter01` through `Chapter10`), plus `Common` for shared helpers and `Appendix` for the list product. Each chapter guide below links to its sources in book order. Each directory has an `Index.agda` importing all of its proofs; `Everything.agda` imports those indexes.

To check just Chapter 6 and its dependencies inside `nix develop`, run `agda -i src src/AoP/Chapter06/Index.agda`. To use its quicksort in another proof, import `AoP.Chapter06.Quicksort`.

## Notation

- `R : B ← A` relates an input `a` to a possible output `b`, written `R b a`. Composition `S ∘ R` applies `R` first.
- `R ⊆ S` sends each witness of `R b a` to a witness of `S b a`.
- `⦅ e ∣ f ⦆` is the list fold with base `e` and step `f`.
- Between `begin` and `∎`, each `≡⟨ law ⟩` cites the law for that step; `≡⟨⟩` uses definitional equality. See [snoc-list associativity](src/AoP/Chapter01/Snoc.agda) and [Horner’s rule](src/AoP/Chapter03/Horner.agda).
