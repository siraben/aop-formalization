## §10.1 Theory

[GreedyDecomposition](../src/AoP/Chapter10/GreedyDecomposition.agda) derives Theorem 10.1 for a relation lifting on `Rel`. Chapter 9 evaluated competing splits before selecting a parent minimum. Here the program chooses a minimum split `c` first. Let `h u` be its result and `h v` a feasible rival obtained at another split `b`. The minimum-split condition compares `c` with `b`; exchange turns the rival into a completion `w` at `c`. Now calculate:

```text
h u  R  h w    both use c: each child minimum beats its feasible rival; apply monotonicity of h
h w  R  h v    exchange bound for the rival at b
```

Transitivity gives the global comparison. Feasibility follows by building the chosen layer from its feasible children. Together these show that the greedy step preserves feasible minima; least-fixed-point induction gives the theorem. This proves an inclusion: an input with no minimum split need not yield an output. [BranchingGreedy](../src/AoP/Chapter10/BranchingGreedy.agda) checks the corresponding argument for a tree of explicit branch choices.

**Proposition 10.1: moving the branch test before minimization.** Suppose legal splits come from either a left or a right branch, and the two ranges are disjoint. Fix an input and test whether it belongs to the left range. If it does, every legal split carries the left tag. Unwrapping the winner’s tag gives a left-branch minimum with the same output. Conversely, tag a left minimum: it beats every left rival, and disjointness rules out right rivals. A negative test gives the corresponding right-branch calculation. If neither branch applies, the right fibre is empty and supplies no winner. [DisjointGreedyBranches](../src/AoP/Chapter10/DisjointGreedyBranches.agda) checks both directions (`forward`, `backward`) with an explicit decision procedure for the left range. It does not require either branch to produce a unique output.

## §10.2 Tab compression

**Why charge the pending blanks?** Suppose the encoder has committed the spelling `xs` and buffered `k` spaces. If the input ends now, it must flush those spaces. [EntabLength.flush-length](../src/AoP/Chapter10/EntabLength.agda) calculates the exact length of that output:

```text
len (blanks xs 0)       = len xs
len (blanks xs (k + 1)) = len (blanks (xs ▻ blank) k)    emit one blank
                        = k + len (xs ▻ blank)            induction on k
                        = (k + 1) + len xs                length of snoc
```

Use this flush length as the charge even while the buffer is still open. For a rival ending in a literal blank, processing that blank raises the charge by at most one. For a rival ending in a tab, [TabBlock.tab-block](../src/AoP/Chapter10/TabBlock.agda) shows that processing its whole expansion emits one tab and leaves zero pending blanks. Its new charge is therefore `1 + len xs ≤ 1 + (k + len xs)`. In each case the rival spelling grew by exactly one character. Induction bounds the final flush length by the length of every spelling with the same expansion; this is the `beats` calculation in `EntabMinimum`.

[Detab](../src/AoP/Chapter10/Detab.agda) expands tabs to blanks at fixed tab stops. [EntabMinimum](../src/AoP/Chapter10/EntabMinimum.agda) proves that the buffered encoder produces a shortest representation at every positive width. [TabPrefixExample](../src/AoP/Chapter10/TabPrefixExample.agda) checks the width-eight example that rules out unrestricted prefix pruning: five glyphs and a tab encode eight columns in six characters, but the seven-column prefix requires at least seven characters. The exercises also examine alternative objectives and the intermediate loop derivation.

## §10.4 TeX decimal output

**Derive the search interval.** A decimal with `k` fractional digits represents `p/D`, where `D = 10^k` and `0 ≤ p < D`. For a target of `n` units of size `1/65536`, half-up rounding accepts this decimal exactly when

```text
n − 1/2 ≤ 65536 p/D < n + 1/2                half-up rounding cell
(2n − 1) D ≤ 131072 p < (2n + 1) D           multiply by the positive integer 2D
```

The left endpoint belongs to the cell; the right one rounds to the next target. For `n = 10` and `D = 10000`, the interval for `131072 p` is `[190000,210000)`. It falls between successive multiples `131072` and `262144`, so width four cannot work. Every shorter decimal can be padded with zeros to width four, ruling those out too. At `D = 100000` the interval becomes `[1900000,2100000)`, admitting `p = 15` and `16`. Both `.00015` and `.00016` are therefore shortest round-tripping decimals.

To choose the closest, compare `|65536 p − 10D|` at the common denominator. The errors are `|983040 − 1000000| = 16960` and `|1048576 − 1000000| = 48576`. Thus `.00015` wins the extra comparison. [TeXClosestTrace](../src/AoP/Chapter10/TeXClosestTrace.agda) checks the two feasible endpoints and both errors; the [rounding guide](tex-rounding.md) connects this grid calculation to the printer.

[TeXExternal](../src/AoP/Chapter10/TeXExternal.agda) specifies shortest round-tripping output and verifies particular values. [TeXShortestSearch](../src/AoP/Chapter10/TeXShortestSearch.agda) gives an exhaustive reference printer. It searches all strings over the [ten digits](../src/AoP/Chapter10/TeXDigitAlphabet.agda) through length 17 and returns a shortest round-tripping string or a proof that none exists. The 17-digit cutoff sends every longer rival to a candidate of no greater length with the same decoded value. This finite search is impractically large. [TeXClosestShortest](../src/AoP/Chapter10/TeXClosestShortest.agda) refines this reference search: among strings of minimum length that decode to the target, it returns one with least absolute error. [TeXDistanceScale](../src/AoP/Chapter10/TeXDistanceScale.agda) checks the common denominator at fixed length and the scores for `.00007` and `.00008`. [TeXSinglePrinter](../src/AoP/Chapter10/TeXSinglePrinter.agda) certifies the single-loop strict-digit printer for the full TeX input range.
