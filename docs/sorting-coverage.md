# §6.6 Sorting by selection

Given a list of natural numbers, return its elements in nondecreasing order, preserving the number of occurrences of each value. For example, `[3,1,2,2]` must yield `[1,2,2,3]`. Selection sort emits one minimum at a time; quicksort splits the input around a pivot and emits the resulting tree in order. Both implementations satisfy the same `Result` specification.

[QuickSplitWork](../src/AoP/QuickSplitWork.agda) checks the intermediate pivot tree for this example. The final `2` is the root: `1` and the other `2` go left, while `3` goes right. Splitting `[1,2]` puts `1` to the left of its pivot `2`. Reading the tree in order gives `[1,2,2,3]`. The root uses three pivot comparisons, the left child uses one, and the singleton inputs use none. The general split proof counts exactly `n−1` pivot comparisons on a nonempty input of length `n`; this count excludes flattening and the cost of comparing the natural numbers themselves. [QuickZeros](../src/AoP/QuickZeros.agda) follows the executable split on `n` zeros: every tied key goes left and the right child is empty. The total comparison count is therefore `tri(n)`, with `tri(0) = 0` and `tri(n+1) = n + tri(n)`. [QuickWorstBound](../src/AoP/QuickWorstBound.agda) proves this bound for every pivot tree: the two child lengths sum to the pass count, and their triangular bounds sum to at most the triangular bound for that combined length. Together with the repeated-zero family this gives a tight worst-case count.
