# Reading and printing TeX decimal fractions

The input is a finite list of digits representing a fraction `0.d₁…dₙ`. The output is a number of units of size `1/65536`, rounded to the nearest unit, with ties rounded upward. For example, the first midpoint is `1/131072 = .00000762939453125`. Removing its last digit changes the output from one unit to zero. [SixteenDigitsFail](../src/AoP/SixteenDigitsFail.agda) checks both outputs against the executable fold.

## From a digit to an integer update

[TeXFraction](../src/AoP/TeXFraction.agda) folds the digits from right to left. The empty suffix has state zero. Prepending digit `d` to a suffix in state `s` gives `⌊(131072d + s)/10⌋`. At the end, `halve` returns `⌊(s+1)/2⌋`. Keeping the extra binary digit until this last step matters: states 9 and 10 both round to 5, but prepending a zero gives states 0 and 1, which round differently.

[QuarterTrace](../src/AoP/QuarterTrace.agda) checks the calculation for `.25`. The state after processing the `5` is `65536`; after processing the `2`, it is `⌊(262144+65536)/10⌋ = 32768`. The final result is `16384` units, exactly one quarter.

## Why discarding a tail can work

Compare the state of the discarded suffix with zero. [TeXStateBound](../src/AoP/TeXStateBound.agda) proves both are below `131072`, so they agree on which multiples of `131072` they reach. The digit update does not have to make the states equal immediately. Instead, each retained digit reduces the spacing between the thresholds on which they agree.

Suppose that spacing is `2v` and divides `131072`. To reach `t·v` **after** division by ten, the numerator must reach `10·t·v = (5t)·(2v)` **before** division. This is an old threshold. Adding `131072d` to each state translates both by a whole number of old blocks. Hence the new states agree at spacing `v`. [DivisionThreshold](../src/AoP/DivisionThreshold.agda) verifies the threshold test for Agda’s integer division primitive; [DecimalGridStep](../src/AoP/DecimalGridStep.agda) combines it with translation for the actual digit update.

Starting at `2¹⁷`, seventeen halvings give spacing one. Two natural numbers that reach the same integer thresholds are equal: test each number as a threshold for the other. Applying `halve` then gives equal rounded outputs. [SeventeenCutoff.cutoff](../src/AoP/SeventeenCutoff.agda) checks this last step for every finite digit list, including inputs shorter than seventeen digits. For a complementary place-value calculation, [SeventeenGrid](../src/AoP/SeventeenGrid.agda) locates every midpoint on the `10⁻¹⁷` grid and [DecimalTailBound](../src/AoP/DecimalTailBound.agda) bounds the discarded fractional part strictly below one grid step.

## Reverse the problem: which decimal should be printed?

For a target `n`, a printer needs a digit list that reads back to `n` and has minimum length among all such lists. The empty fractional part reads as zero; `.5` reads as 32768 and the only shorter candidate is empty. [TeXExternal](../src/AoP/TeXExternal.agda) checks these two shortest outputs.

The cutoff gives a finite reference algorithm. Enumerate words over the [ten digits](../src/AoP/TeXDigitAlphabet.agda) of lengths zero through seventeen, retain words that read as `n`, and minimize length. To compare the winner with **any** rival `es`, compare it first with `take 17 es`: that prefix is listed, it reads to the same value, and its length is at most that of `es`. The same argument makes an empty search result conclusive. [TeXShortestSearch](../src/AoP/TeXShortestSearch.agda) implements both cases. The list has `1 + 10 + … + 10¹⁷` entries; this proof of exhaustive coverage leaves the efficient greedy printer as a separate derivation.

Shortestness alone gives no preference between equal-length outputs. For a `k`-digit fraction with numerator `p`, the distance to `n/65536` is `|65536p − n·10ᵏ| / (65536·10ᵏ)`. At fixed length compare the numerators. For example `.00007` and `.00008` both read as 5. The target numerator on this common scale is `5·100000 = 500000`; the candidate numerators are `458752` and `524288`. Their errors are therefore `41248` and `24288`: `.00008` is closer. [TeXDistanceExample](../src/AoP/TeXDistanceExample.agda) checks these integer calculations. This comparison concerns these two candidates; it does not establish global optimality of either by itself.

[TeXGreedyTieTrace](../src/AoP/TeXGreedyTieTrace.agda) checks what the book’s upper-endpoint digit rule actually prints for target 10. Starting at `(19,21)`, the first three zeroes give `(19000,21000)`. The next digit, `1`, leaves `(58928,78928)`, and the final digit, `6`, crosses the lower endpoint and stops the run. Both `.00016` and `.00015` read back as 10, but the latter has the smaller error numerator (`16960` versus `48576`). Thus even when the printer terminates and round-trips, its upper-endpoint choice can lose to an equally short rival on distance.

[TeXGridStop](../src/AoP/TeXGridStop.agda) proves the stopping test for one width. If `z·W < H ≤ (z+1)·W`, then every numerator below the upper endpoint is at most `z`. If `L ≤ z·W`, `z` is the greatest feasible numerator; if `z·W < L`, the entire width is infeasible. [TeXGridDigit.advance](../src/AoP/TeXGridDigit.agda) proves the corresponding digit step. Write the current upper endpoint as `H = z·W + q`. If `d·W < 10q ≤ (d+1)·W`, adding `10z·W` throughout gives `(10z+d)·W < 10H ≤ (10z+d+1)·W`. Thus appending the local digit gives the greatest numerator strictly below the next upper endpoint. [TeXUpperResidual](../src/AoP/TeXUpperResidual.agda) checks the state passed to the next step: `r = 10q − d·W` satisfies `1 ≤ r ≤ W`, and `(10z+d)·W + r = 10H`. At an exact upper endpoint the strict digit leaves residual `W`. [TeXStrictDigit](../src/AoP/TeXStrictDigit.agda) proves that `q ≤ W` makes the next strict digit at most 9: `d·W < 10q ≤ 10W`. This includes the next step from `q = W`, where ordinary division would yield 10. For the lower endpoint, [TeXLowerResidual](../src/AoP/TeXLowerResidual.agda) cancels the old prefix from `10L − (10z+d)·W`, leaving the truncated difference `10p − d·W`. A zero difference certifies the lower bound; a positive difference reconstructs the exact lower endpoint for the next iteration. [TeXPrinterStep.Emit](../src/AoP/TeXPrinterStep.agda) combines these laws into one executable transition: given `0 < q ≤ W`, it computes the strict quotient digit, appends it, and returns the two updated residuals with their endpoint equations.

Why do five places suffice? [TeXIntervalGrowth](../src/AoP/TeXIntervalGrowth.agda) starts with the positive target’s endpoints `L` and `L+2`. Each digit multiplies both by ten, so at five places their difference is `200000`. By [TeXFivePlaces](../src/AoP/TeXFivePlaces.agda), that width exceeds the grid spacing `131072`: the greatest grid point strictly below the upper endpoint must already meet the lower bound. [TeXFirstGrid](../src/AoP/TeXFirstGrid.agda) uses a known feasible final width to certify the first occupied grid and its greatest feasible numerator. [TeXGridMinimum.Positive.optimum](../src/AoP/TeXGridMinimum.agda) supplies those witnesses by strict integer division at each width and the five-place bound. [TeXExactState](../src/AoP/TeXExactState.agda) identifies the decoder state for a decimal with numerator `p` and denominator `v` as `⌊131072p/v⌋`. [TeXRoundInterval](../src/AoP/TeXRoundInterval.agda) then proves both directions: for a positive target `n`, `intern` returns `n` exactly when `(2n−1)v ≤ 131072p < (2n+1)v`. [TeXEmitNumerator](../src/AoP/TeXEmitNumerator.agda) proves the one-digit link: appending `d` changes a prefix’s numerator from `p` to `10p+d` and denominator from `v` to `10v`, including when `d` is zero. [TeXPrefixRun](../src/AoP/TeXPrefixRun.agda) carries that valuation through every emitted digit. At the first occupied width, [TeXOccupiedPrefix](../src/AoP/TeXOccupiedPrefix.agda) identifies the prefix numerator with the greatest feasible numerator. [TeXPrefixShortest](../src/AoP/TeXPrefixShortest.agda) concludes that for positive TeX targets in range the resulting digits round-trip and are at least as short as every rival. This implementation determines the width by a grid scan, then emits that many digits. [TeXResidualLoop](../src/AoP/TeXResidualLoop.agda) combines the stop test and digit emission in one fuel-bounded loop. With `W=10` and endpoints `[4/10,5/10)`, it emits `4` and stops, so the excluded endpoint `.5` is never printed. [TeXResidualGap](../src/AoP/TeXResidualGap.agda) shows that every continuing step multiplies the residual gap by ten. [TeXLoopTermination.five](../src/AoP/TeXLoopTermination.agda) therefore rules out fuel exhaustion: with initial gap at least two, five continuing steps would require more room than the upper residual permits. Agreement of the returned digits with the certified two-pass printer remains open.

For the fixed TeX width, `python3 checks/tex_printer_domain.py` runs an [integer audit](../checks/tex_printer_domain.py) over all 65536 specified targets. At width `k` it checks the interval `[(2n−1)10ᵏ/W,(2n+1)10ᵏ/W)` for an integer: each skipped width has none, and at termination the printed numerator is the greatest one. No executed digit step has an integral upper endpoint. The observed counts for lengths 0 through 5 are respectively `1, 9, 90, 900, 9000, 55536`. The script also decodes every digit string of width zero through five by the right-to-left `intern` recurrence. In the resulting groups the printed string is always the greatest shortest candidate. It is strictly farther than a closest candidate for **13776** targets. Keeping the shortest width `k`, rounding `n·10ᵏ/65536` to the nearest integer (ties upward), and capping at `10ᵏ−1` returns a closest candidate in every group. These are exhaustive executable checks for `W=131072`; the Agda shortestness proof above applies to the strict-digit implementation with a separate width scan.
