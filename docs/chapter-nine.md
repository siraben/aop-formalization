# Chapter 9: dynamic programming

## §9.1 Theory

[DPBifunctor](../src/AoP/DPBifunctor.agda) derives Proposition 9.4 for a two-argument relator. Compare labels by `U` and subproblems by `V`. Reflexivity on labels gives the ordinary monotonicity condition. For thinning, `prune` starts with a discarded decomposition and its evaluated layer, composes the lifted comparisons, and splits them again to produce a feasible retained layer whose combined result is at least as good. The relator, evaluator and subproblem comparison laws are explicit hypotheses.

[DPCostFactor](../src/AoP/DPCostFactor.agda) derives Proposition 9.2. Rank solutions by comparing their costs. `move-cost` transfers a comparison of solutions to their costs, and `move-layer` lifts that transfer to a layer of recursive results. If the cost of evaluating a layer is computed by a monotone cost function `k`, then `monotone` proves that the original evaluator preserves the solution ranking. The proof uses the stated relator laws and agreement of the lifted cost graph with the graph of its action on layers.

[DPContextCost](../src/AoP/DPContextCost.agda) derives Proposition 9.3 when the cost calculation also uses the child inputs. `transfer` pairs each cost with its input: if two child results share an input, simplicity of the converse feasibility relation ensures the two input labels agree. `Factor.monotone` lifts that comparison and applies the cost function to the two paired layers. Its factorization hypothesis requires a paired layer for each layer being evaluated and agreement on cost for every such pairing.

[TaggedThinning](../src/AoP/TaggedThinning.agda) checks both injection laws in exercise 9.5. When every input candidate has the same tag, every retained candidate has that tag. Removing the tags gives a thinning under that branch’s comparison, and every such thinning can be lifted back. [DisjointFibres](../src/AoP/DisjointFibres.agda) shows that the two ranges are disjoint exactly when restricting the right range to the complement of the left leaves it unchanged. Given a decision procedure for membership in the left range, the inverse fibre of the copair is obtained by selecting the corresponding tagged fibre. [DisjointMinimum](../src/AoP/DisjointMinimum.agda) derives the direct-image version under that range test. `SelectBranch.forward` projects the retained set to the selected tag and preserves its evaluated outcomes, hence its minima. `backward` tags each retained alternative to reconstruct a thinning and minimum for the full copair. [DisjointPowerMinimum](../src/AoP/DisjointPowerMinimum.agda) gives Proposition 9.1 with the book’s power relator: every retained input must have a selected outcome and every selected outcome must come from a retained input. `project` and `inject` transport both coverage witnesses and preserve the very same outcome set and minimum. [BranchOutcomeChoice](../src/AoP/BranchOutcomeChoice.agda) shows why the distinction matters: one retained input has outcomes 2 and 9. The power relator permits selecting `{9}`, whose minimum is 9; the direct image contains both outcomes and has minimum 2. Outside both ranges the selected fibre is empty, so neither side can return a minimum.

## §9.2 The string edit problem

[ScriptLengthOrder](../src/AoP/ScriptLengthOrder.agda) verifies exercise 9.6. Prepending one command to each script preserves their length comparison, even when the commands differ. This proves the point-free cons monotonicity law for the shortest-script objective.

[EditCellCount](../src/AoP/EditCellCount.agda) counts interior table updates. Advancing a row visits one interior cell per target letter, and tabulation advances one row per source letter. For lengths `p` and `q` the exact count is `p*q`. This measure excludes boundary initialization, letter comparison, and computing or comparing script lengths.

[CachedEditCell](../src/AoP/CachedEditCell.agda) checks the book’s script-length cache for an interior cell. Matching letters copy the diagonal entry; unequal letters compare the two neighbouring cached lengths. Each branch prepends one command and increments the chosen length. The returned script is shortest and the cache equals its operation count. [CachedEditTable](../src/AoP/CachedEditTable.agda) builds the complete table from these entries. Empty-string boundaries admit only insertions or only deletions; each interior update uses the diagonal, below, and right entries. `solve` returns a shortest script and its certified length for any alphabet with decidable equality.

[EditListMinimum](../src/AoP/EditListMinimum.agda) gives the external command-list specification. The returned list decodes to the requested pair of strings. Every competing command list decoding to that pair induces a typed competitor with the same operation count, so the returned list is at least as short.

[EditTableExample](../src/AoP/EditTableExample.agda) checks all nine entries for `ab → ba`. With target suffixes `ba`, `a`, and the empty string, the costs are:

| Source suffix | `ba` | `a` | empty |
| --- | ---: | ---: | ---: |
| `ab` | 3 | 2 | 2 |
| `b` | 2 | 2 | 1 |
| empty | 2 | 1 | 0 |

At `ab → ba`, deleting `a` and inserting `b` tie as first moves. The solver chooses deletion, then copies `b` and inserts `a`. Copies count as operations, giving three commands in total.

## §9.3 Optimal bracketing

[MatrixBracketCost](../src/AoP/MatrixBracketCost.agda) checks the size and cost functions in exercise 9.10. A matrix product of sizes `i × k` and `k × j` has size `i × j` and adds `i·k·j` scalar multiplications to the two subtree costs. For input dimensions `2 × 3`, `3 × 4`, and `4 × 5`, the two bracketings cost 64 and 90, respectively. The type indices ensure that each intermediate product has compatible dimensions. The cost counts ordinary dense scalar multiplications.

[AssociativeBrackets](../src/AoP/AssociativeBrackets.agda) proves exercise 9.12. Folding the nonempty list of leaves equals folding the bracketing tree directly. The intermediate append law uses associativity alone; nonempty lists eliminate the need for a unit.

[BracketMinimum](../src/AoP/BracketMinimum.agda) gives an exhaustive bracketing solver and [AppendOptimal](../src/AoP/AppendOptimal.agda) proves optimality for the list-append cost model. The same-input optimal-subtree argument and enumerator support comparison with the book’s interval algorithm.

## §9.4 Data compression

The [dictionary encoder guide](dictionary.md) gives a row-by-row cost calculation and follows the proof from decoding to the reduced table.

[DictionaryExamples](../src/AoP/DictionaryExamples.agda) checks the three worked decoding examples: an overlapping copy extends `aba` to `ababab`, a literal and one pointer decode to ten copies of `a`, and the mixed literal/pointer sequence decodes to `aababacab`. The formal pointer stores its copy length minus one.

[DictionarySearch](../src/AoP/DictionarySearch.agda) certifies a least-cost encoding by bounded exhaustive search. [DictionarySplice](../src/AoP/DictionarySplice.agda) proves a replacement law for deriving a prefix table with fixed literal and pointer charges. If two instruction sequences decode to the same text, appending any common continuation yields the same decoder result, including failure. The cheaper prefix remains cheaper or tied after appending. This justifies retaining one cheapest encoding per decoded prefix. [DictionaryTable](../src/AoP/DictionaryTable.agda) computes entries in increasing prefix length. For each earlier entry it tests one-token extensions against the new prefix; a literal extension from the preceding entry guarantees a feasible fallback. Each entry carries a proof that its program decodes to its prefix. [DictionaryTableTrace](../src/AoP/DictionaryTableTrace.agda) checks `aaaa` with literal charge 2 and pointer charge 3: `a` and `aa` use literals, while the four-letter entry uses a literal followed by a three-letter overlapping copy for cost 5. [DictionaryScanBound](../src/AoP/DictionaryScanBound.agda) proves the local cost bound: `edge` shows the selected entry costs at most any tested one-token extension that reaches this prefix, and `pass` bounds it by the fallback. [DictionaryLastEdge](../src/AoP/DictionaryLastEdge.agda) decomposes every successful nonempty rival program into an earlier program and its final instruction. `earlier` exhibits the nonempty suffix added to the predecessor text, including when the pointer overlaps its destination. [DictionaryTokenCoverage](../src/AoP/DictionaryTokenCoverage.agda) proves that every instruction in any successful prefix encoding belongs to the table’s finite token list: appending literals for the remaining text gives a full-target run to which the alphabet and pointer bounds apply. [DictionaryHistory](../src/AoP/DictionaryHistory.agda) proves that appending one letter adds exactly one new strict prefix, the previous whole text. `Rows.advance` uses that split to locate a row for any strict prefix in the extended history. [DictionaryBellman](../src/AoP/DictionaryBellman.agda) combines these facts: if each earlier prefix has an optimal row, `best` proves the computed next row beats or ties every feasible rival program. [DictionaryOptimal](../src/AoP/DictionaryOptimal.agda) threads the invariant through `fill`: the empty program is optimal at the empty prefix, and each new row extends the history with another optimal encoding. `minimum` proves that the returned program costs at most every program decoding to the target, for decidable letter equality and fixed natural literal and pointer charges. [LongestPointerDominance](../src/AoP/LongestPointerDominance.agda) proves the pointer comparison behind the selective transition rule. Given two pointers ending at the same target, trim the rival’s preceding program to the earlier prefix; its optimal row costs no more, and either pointer adds the same charge. [LongestPointerScan](../src/AoP/LongestPointerScan.agda) computes the longest legal pointer among the supplied history rows and target-bounded tokens. It returns a legal hit with a proof of maximal copied length, or proves no pointer hits the prefix. [PointerSpanOrder](../src/AoP/PointerSpanOrder.agda) turns that length comparison into the prefix witness needed by pointer dominance: cancel trailing letters of the two successful copies until the shorter path is exhausted. The remaining path runs from the longer pointer’s starting state to the shorter pointer’s starting state. [ReducedDictionary](../src/AoP/ReducedDictionary.agda) uses one cost comparison per prefix with a legal pointer: the longest pointer competes with appending the last literal. [ReducedDictionaryTrace](../src/AoP/ReducedDictionaryTrace.agda) checks the decisions on `aa`, `aaa`, and `aaaa` for charges 2 and 3: the second letter stays literal; the next two entries copy two and three letters respectively. The reduced table carries decoding certificates. [ReducedPointerBound](../src/AoP/ReducedPointerBound.agda) proves that the reduced choice costs no more than its literal fallback or any tested pointer extension from an optimal history, even if the rival used a different program for the pointer’s start state. [ReducedBellman](../src/AoP/ReducedBellman.agda) factors each nonempty rival at its last instruction: a final literal must append the same letter to the same prefix, and a final pointer falls under `pointer-bound`. [ReducedDictionaryOptimal](../src/AoP/ReducedDictionaryOptimal.agda) carries both prefix coverage and optimality of every stored row through `fill`. Its `minimum` certifies the reduced encoder against every program decoding to the target, including tied and zero-cost encodings. Finding the longest pointer scans history rows and bounded tokens.
